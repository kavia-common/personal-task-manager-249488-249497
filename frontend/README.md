# Personal Task Manager (Frontend)

A modern React todo app with **Ocean Professional** styling:
- Primary: `#2563EB` (blue)
- Secondary: `#F59E0B` (amber)
- Subtle shadows, rounded corners, minimalist layout
- **Local persistence** via `localStorage`
- CRUD: create, edit, complete, delete
- Filtering: all / active / completed
- Search and drag-to-reorder prioritization

## Running

```bash
npm install
npm start
```

Preview is expected to run on **port 3000** via the platform's preview manager.

## Environment variables (optional future backend integration)

The app runs fully local-first. If a backend is added later, these can be used:

- `REACT_APP_API_BASE`
- `REACT_APP_BACKEND_URL`
- `REACT_APP_WS_URL`
- `REACT_APP_FRONTEND_URL`
- `REACT_APP_NODE_ENV`
- `REACT_APP_ENABLE_SOURCE_MAPS`
- `REACT_APP_PORT`
